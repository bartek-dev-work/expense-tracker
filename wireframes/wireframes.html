Adnotacje — mobile
  • 1
    Top bar — logo + tytuł + avatar. Tap avatar → ekran 5 (Ustawienia).
  • 2
    Karta balansu — kwota + budżet + pasek postępu. Stan ostrzegawczy gdy > 90% (pasek ciemny).
  • 3
    Skróty czasowe — Dziś / Tydzień / Miesiąc. Tap → filtr listy (ekran 2).
  • 4
    Wykres kategorii — donut + legenda 5 pozycji. Tap segmentu → ekran 4 z filtrem kategorii.
  • 5
    Lista ostatnich wydatków — 5 wierszy. Tap wiersza → szczegóły wydatku (modal).
  • 6
    FAB + — primary action. Stany: default / pressed (ciemniejsze tło). Tap → ekran 3.
  • 7
    Bottom nav — 5 pozycji, środkowy „+" wyróżniony. Stany: active (czarny tekst) / inactive (szary).
Adnotacje — desktop
  • A
    Top bar + global search — search dostępny ze wszystkich ekranów. Tap input → focus, podpowiedzi (dropdown).
  • B
    Sidebar — 5 pozycji jak w bottom-nav mobile. Aktywna pozycja: szare tło + border.
  • ·
    Layout 3-kolumnowy dla statystyk (balans + Dziś + Tydzień/Miesiąc), 2-kolumnowy dla wykresu i listy.
  • ·
    Stany danych: empty (brak wydatków → CTA „Dodaj pierwszy"), loading (skeleton), error (komunikat + retry).

Adnotacje
  • 1
    Header — tytuł + close (X). Tap X → potwierdzenie odrzucenia jeśli formularz dotknięty.
  • 2
    Pole kwota (focus) — duży display, otwiera numpad (mobile) / input (desktop). Walidacja: > 0.
  • 3
    Siatka kategorii 4×2 — tap = wybór (czarna ramka). „+ nowa" → ekran 5 (zarządzanie kategoriami).
  • 4
    Data — tap → date picker. Domyślnie dzisiaj.
  • 5
    Opis — text input z podpowiedziami (autocomplete z historii).
  • 6
    Notatka — textarea, opcjonalna.
  • 7
    CTA — „Zapisz" disabled gdy kwota = 0 lub kategoria niewybrana. Po zapisie → toast „Dodano" + powrót do poprzedniego ekranu.
Stany formularza
  • Default — wszystkie pola puste, przycisk Zapisz disabled.
  • Filling — przy każdej zmianie autosave do localStorage (przywrócenie po zamknięciu).
  • Validation error — pole z czerwonym borderem? (W lo-fi: pogrubiony border + 1-line message pod polem).
  • Saving — Zapisz pokazuje spinner.
  • Success — toast 2s, modal zamyka się.
  • Error API — banner u góry modala + Retry.

Adnotacje
  • 1
    Profile card — tap → edycja profilu (osobny ekran).
  • 2
    Kategorie — wiersz nawigacyjny ze strzałką → ekran zarządzania (CRUD).

    Eksport CSV — primary button. Stany: idle / loading / done (toast „Plik gotowy").
Wzór wiersza
  • Każdy wiersz: label + meta (lewy slot) + kontrola (prawy slot) + dolny border 1px solid #999.
  • Kontrole: › (nav), input, select, toggle, button.
  • Stany hover/focus na desktopie: jasnoszare tło wiersza.
  • Disabled: szary tekst + brak interakcji.
  • Error inline: pasek pod kontrolą z opisem błędu.

Notatki

Następne kroki

  1. Zatwierdzić strukturę i przepływy → wskazać 1–2 ekrany do iteracji.
  2. Zdefiniować edge cases: pierwszy login (empty), przekroczenie budżetu, offline.
  3. Przejść z lo-fi na hi-fi: typografia, ikony, paleta kolorów, przykłady ilustracji.
  4. Zaprojektować mikro-interakcje (np. animacja paska postępu, toast po zapisie).
  5. Specyfikacja komponentów (button, input, chip, list-row, card) jako mini design-system.
